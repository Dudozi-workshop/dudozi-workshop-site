# 두도지공방 홈페이지

Cloudflare Pages Git 연동을 위한 초기 소스입니다. 저장소는 `Dudozi-workshop/dudozi-workshop-site`이며, Cloudflare 연결·배포는 아직 완료되지 않았습니다.

## 최초 연결

1. Dudozi-workshop 계정에 홈페이지 전용 GitHub 저장소 `dudozi-workshop-site`를 생성합니다. 기존 앱 저장소와 분리합니다.
2. 이 폴더의 소스를 `main` 브랜치에 올립니다.
3. Cloudflare에 로그인 후 Workers & Pages에서 Pages 프로젝트를 만들고 해당 GitHub 저장소를 연결합니다. 저장소 접근 권한은 해당 저장소만 선택합니다.
4. 아래 설정으로 첫 배포를 실행합니다.

| 설정 | 값 |
|---|---|
| 프로젝트 이름 후보 | dudozi-workshop |
| 프로덕션 브랜치 | main |
| 프레임워크 | None |
| 빌드 명령 | npm run build |
| 빌드 출력 디렉터리 | dist |
| 루트 디렉터리 | 저장소 루트 |

프로젝트 이름과 최종 주소는 Cloudflare 결과를 확인한 후 확정합니다.

## 수정 및 반영

연결 후 ChatGPT의 GitHub 연결을 통해 소스를 수정할 수 있습니다. `main`에 반영하면 Cloudflare Pages가 자동 배포합니다. 변경 전 최신 소스를 확인하고 `npm run build`로 검증합니다. 배포 성공 상태를 확인한 후에만 실제 반영 완료로 보고합니다. 개발 브랜치는 미리보기로 검토하고 검토 완료 후 main에 반영합니다.

GitHub 연결만으로 Cloudflare 계정 설정·도메인·배포 로그에 직접 접근할 수 있는 것은 아닙니다. 계정 관리에는 Cloudflare 로그인 또는 별도 연결이 필요합니다. API 토큰을 채팅에 공유하지 않습니다.

## 현재 기능

- 공방 소개, MY LOCK·DZlog 소개, 모바일 화면 대응.
- 문의와 다운로드는 준비 중 상태입니다. 접수 폼, 이메일 발송, 관리대장, 개인정보 처리 안내는 아직 연결되지 않았습니다.
- 외부 폰트·추적 코드·외부 이미지·유료 서비스 없이 정적 페이지로 구성했습니다.

## 다음 연결

공식 다운로드 주소와 접수처를 확인한 후 연결합니다. 문의 데이터는 공개 GitHub 저장소에 기록하지 않습니다. 자동 접수·알림 기능은 별도 구현·검증 후 활성화합니다.
