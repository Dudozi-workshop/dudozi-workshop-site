## Stitch에 입력할 디자인 요청

두도지공방 웹사이트 PC Hero에 들어가는 그리글 카드의 **시각적 완성도만** 높여주세요. 새로운 홈페이지·새 앱을 만들지 마세요.

- 출력: A/B 두 가지의 디자인 시안, **가로 비율 276:194**. 개별 카드만 디자인하며 고해상도 렌더에서 작은 실제 카드의 가독성까지 고려.
- A: 따뜻한 세이지/아이보리, 실제 키보드의 방향 입력부를 선명하게 보여주는 간결한 기기형 구성.
- B: A와 동일한 구성 규격이나 **손가락 제스처 궤적**을 보다 직관적이고 자연스럽게 표현한 구성.
- 왼쪽: 공식 그리글 아이콘(제공한 원본)을 사용, 앱 이름 **그리글**, 설명 **“방향으로 입력하는 새로운 한글 키보드”**.
- 오른쪽: 작은 스마트폰/키보드 표현. 입력창, 중앙 4방향 입력부, 필요한 경우 `En`, `Space`, `Enter`를 간결하게 사용.
- 손가락 위치와 이동 궤적이 한글의 방향 제스처 입력 기능을 나타내야 함. 손가락이 화면을 덮거나 지나치게 커지면 안 됨.
- 그리글은 **그림 그리기·필기·메모 앱이 아닌 한글 키보드/IME**.
- 아직 확정되지 않은 V2 자모별 방향 매핑은 임의로 만들어 보여주지 말 것.
- 앱 설정 화면, 온보딩, 인증 화면, 무의미한 상태 배지/영문 장식, 임의 녹색 나뭇잎 앱 아이콘 추가 금지.
- 앱 소개 상세 페이지나 다른 두 카드의 UI/문구/링크는 변경 대상이 아님.
- 사이트 브랜드 톤: 밝은 베이지·세이지 그린·절제된 브라운. 깔끔하고 부드러운 모서리, 충분한 여백.
- 실제 앱 스크린샷이 아닌 경우에는 **기능 설명용 콘셉트 표현**이라는 사실을 인계 문서에 적어 둘 것.
- 최종 제공물: A/B 개별 카드 이미지, A/B 차이 설명 3줄, 적용 가능한 레이아웃·색상·구성 변화, 사용한 자산 목록.

## Stitch에 제공할 자료

- 현재 비운영 PC 홈페이지 Preview의 그리글 카드 스크린샷.
- 공식 앱 아이콘: `public/assets/app-grigle-launcher.webp`.
- 참고용 현재 HTML/CSS: `public/index.html` 내 `ddzv4-grigle`, `public/home-hero-v4-pc.css` 내 `ddzv4-*` 카드 CSS.
- 가능하다면 사용자가 이전에 제공한 실제 그리글 키보드 화면 캡처.
- 주의: Preview URL만 입력했다고 Stitch가 비공개 프로젝트나 GitHub 코드를 자동으로 읽는다고 가정하지 않는다. 필요한 사진과 아이콘은 직접 제공한다.

## 승인 이후 Antigravity 인계

**선택된 시안 A 또는 B만** 재현한다. 작업 대상은 `public/index.html`의 `ddzv4-grigle` 블록과 `public/home-hero-v4-pc.css`의 그리글 카드 선택자에 한정한다.

**변경 금지:** `ddzv4-cards` 외부 크기, 그리글 276×194px 카드 외곽, 카드 간격 12px, DZlog/MY LOCK 카드 내부, 전체 Hero 배경, 슬로건, CTA, 하단 가치 띠, 모바일 Hero, 운영 `main`.

시안에 새 이미지가 포함된다면 원본·라이선스 확인 후 `public/assets/`로 추가한다. 이미지 안에 부정확한 한국어가 있다면 실제 HTML 텍스트를 우선 사용한다.

검수 증거: 변경 diff, `npm run build`, PC 1440/1280/1100px 캡처, 모바일 회귀 확인, Vercel Preview(요청 시), 사용자 최종 승인.
