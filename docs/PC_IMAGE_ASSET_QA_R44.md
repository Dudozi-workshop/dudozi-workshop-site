## 후속 구현 정책
1. **사전 동의 없이 MY LOCK Candy Soft R2 원본의 색상/형태/질감을 수정하지 않는다.**
2. `scene.webp`을 일기장 이미지로 교체하지 않는다. DZlog는 식물·실험 사진 위에 표를 기록하는 **카메라**로 유지한다.
3. 저해상도 배경 이미지를 무작정 CSS로 확대하지 말고, 고해상도 정품 소스 확보 시 원본 비율/구도 보존 상태에서 교체한다.
4. 외부 Unsplash 히어로 사진과 현장 목업의 출처를 구분한다. 실제 Android 앱 스크린샷이 아닌 제품 연출 화면은 계속 `구성 예시`로 표기한다.
5. 신규 에셋 적용 시 로컬 Playwright 1440/1280/1100px 촬영, WebP 크기/파일 크기, 라이선스, 모바일 영향까지 확인하고 커밋한다.
