# PC Hero v4 — 단계별 구현 관리

- 기준: 2026-10-14 승인된 PC Hero v4 HTML 목업
- 작업 브랜치: `feat/homepage-visual-r3-hifi`
- 운영: `main` 및 Cloudflare Pages 변경 금지, 사용자 요청 전 프리뷰 배포 금지
- PC 적용 범위: 1051px 이상; 1050px 이하 기존 R4 히어로 유지

## 1차 구현 (완료: 코드 반영)

- 신규 PC 영역: 좌측 38px 슬로건과 CTA 2개, 우측 548×400px 앱 카드군
- DZlog: 260×400px 사진·표 중심 콘셉트; 실제 캡처 확보 후 교체
- 그리글: 276×194px; **기존 공식 앱 아이콘** + “방향으로 입력하는 새로운 한글 키보드” + 입력창/자음·모음 2영역/4방향을 암시하는 손가락 제스처
  - V2 자모별 방향 Mapping 미확정: 제스처를 특정 자모 입력의 확정 규칙처럼 표시하지 않음
- MY LOCK: 276×194px 임시 내부 콘셉트, 별도 최종 디자인 작업 예정
- 카드 간격 12px; DZlog 높이 = 그리글 194px + 간격 12px + MY LOCK 194px
- 하단 철학 띠 74px, 중심 좌표 22.222% / 50% / 77.778%
- 제품 상세, 앱 소개, 공방 이야기 실제 링크 연결
- 승인 전 외부 히어로 사진을 교체하지 않음. 현재 사진은 기존 R4에서 검수한 고해상도 Unsplash 참조 재사용; 승인한 v4 배경 JPEG를 사이트 자산으로 확정/이식하는 작업은 별도 후속 단계

## 수정 파일

- `public/index.html`: PC 전용 히어로/가치 영역 추가, 기존 모바일 히어로 보존
- `public/home-hero-v4-pc.css`: PC 규격과 독립된 카드 내부 스타일 관리

## 검증 상태

- PASS: 소스 재조회, 중복 ID 없음, 내부 링크, 아이콘 참조, 그리드 치수 일치, 하단 좌표, CSS 중괄호, 모바일/PC 경계 규칙
- PASS: `vercel.json`의 현재 브랜치 Vercel 자동배포 차단 설정 유지
- **보류**: 전체 npm 빌드 및 Chromium 실화면 QA — GitHub Actions 실행 실패는 `runner_id=0 / steps=[]`로 작업 실행 전 종료. 성공으로 간주하지 않음.
- 배포: 수행하지 않음
