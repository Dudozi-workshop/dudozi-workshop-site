# PC Hero v4 — 단계별 구현 관리

- 기준: 2026-10-14 승인된 PC Hero v4 HTML 목업
- 작업 브랜치: `feat/homepage-visual-r3-hifi`
- 운영: `main` 및 Cloudflare Pages 변경 금지, 사용자 요청 전 프리뷰 배포 금지
- PC 적용 범위: 1051px 이상; 1050px 이하 기존 R4 히어로 유지

## 1차 구현 (완료: 코드 반영)

- 신규 PC 영역: 좌측 38px 슬로건과 CTA 2개, 우측 548×400px 앱 카드군
- DZlog: 260×400px 사진·표 중심 콘셉트; 실제 캡처 확보 후 교체
- 그리글: 276×194px; **기존 공식 앱 아이콘** + “방향으로 입력하는 새로운 한글 키보드” + 입력창/자음·모음 2영역/4방향을 암시하는 손가락 제스처
  - V2 자모별 방향 Mapping 미확정: 제스처를 특정 자모 입력의 확정 규칙처럼 표시하지 않음
- MY LOCK: 276×194px 임시 내부 콘셉트, 별도 최종 디자인 작업 예정
- 카드 간격 12px; DZlog 높이 = 그리글 194px + 간격 12px + MY LOCK 194px
- 하단 철학 띠 74px, 중심 좌표 22.222% / 50% / 77.778%
- 제품 상세, 앱 소개, 공방 이야기 실제 링크 연결
- 승인 전 외부 히어로 사진을 교체하지 않음. 현재 사진은 기존 R4에서 검수한 고해상도 Unsplash 참조 재사용; 승인한 v4 배경 JPEG를 사이트 자산으로 확정/이식하는 작업은 별도 후속 단계

## 수정 파일

- `public/index.html`: PC 전용 히어로/가치 영역 추가, 기존 모바일 히어로 보존
- `public/home-hero-v4-pc.css`: PC 규격과 독립된 카드 내부 스타일 관리

## 검증 상태

- PASS: 소스 재조회, 중복 ID 없음, 내부 링크, 아이콘 참조, 그리드 치수 일치, 하단 좌표, CSS 중괄호, 모바일/PC 경계 규칙
- PASS: `vercel.json`의 현재 브랜치 Vercel 자동배포 차단 설정 유지
- **보류**: 전체 npm 빌드 및 Chromium 실화면 QA — GitHub Actions 실행 실패는 `runner_id=0 / steps=[]`로 작업 실행 전 종료. 성공으로 간주하지 않음.
- 배포: 수행하지 않음


## 4차 구현 (2026-10-15, PC Hero 세로 높이 안정화)

- 증상: 휴대폰 브라우저에서 '데스크톱 사이트'를 요청하거나, 브라우저가 비정상적으로 긴 뷰포트를 보고하면 첫 화면 Hero가 지나치게 길어짐.
- 원인: Hero와 내부 레이아웃이 공통으로 `min-height:max(646px,100vh - 74px)`를 사용하여 높은 뷰포트에서 상한 없이 확장됨.
- 수정: 공통 토큰 `--ddzv4-hero-height:clamp(646px, 100vh - 74px, 780px)`로 범위 제한. 지원하는 브라우저에서는 `100svh`로 안정적인 viewport 높이를 우선 사용.
- 보호: 좌측 슬로건 38px, 카드군 548×400px(260+12+276), 하단 가치 띠 74px 및 2.5/5/7.5 위치, 배경·모바일 미수정.
- 회귀검사: 최대높이 토큰·상한 적용·두 Hero 블록 공통값·이전 무제한 계산식 재도입 금지를 정적 QA에 추가.
- 후속: 검수용 비운영 프리뷰에서 실제 데스크톱/데스크톱 사이트 모드의 화면 위치 확인. 운영 배포 금지 유지.

## 3차 구현 (2026-10-15, 소스 반영)

- **DZlog 카드**: 사진 중심 A안 유지, RECORD 표시·촬영 프레임 모서리·투명 표·파일명 `T1_01.jpg`·셔터 레이아웃 보강. 자동 AI 분류로 오인될 수 있는 문구 없음.
- 기존의 저해상도 `scene.webp` 배경을 배제하고 앞서 승인된 식물 촬영 콘셉트를 `public/assets/dzlog-hero-photo-concept.webp`로 최적화해 적용. **실제 DZlog 앱 화면 캡처가 아닌 기능 설명 예시**이며, 실제 캡처 교체는 후속 단계.
- **배경**: 승인된 PC Hero v4 목업의 따뜻한 자연광·잎 그림자·우드 데스크 원본을 `public/assets/ddz-hero-v4-approved.webp`로 최적화해 저장하고 CSS로 직접 연결. 기존 임시 Unsplash 배경은 신규 PC Hero에서 제거.
- 카드 크기 548×400px(260 + 12 + 276), 좌측 38px 슬로건, 하단 74px 및 2.5/5/7.5 앵커 유지
- 정적 검사에 승인된 두 이미지 파일 필수 존재 및 CSS 참조 확인 추가
- 이미지 원본 보관: 이전 `ddz_pc_hero_v4_files.zip` 생성 산출물의 원본 사진. 압축 WebP는 시각 내용이 동일하지만 품질 손실(웹 최적화) 가능. 필요 시 원본에서 재인코딩.
- 운영 `main`/Cloudflare 배포 금지 유지. 프리뷰 전 정적 QA + Vercel 빌드 검증 별도.

## 2차 구현 (2026-10-14, 코드 반영)

- **그리글**: 사용자 제공 실제 키보드 스크린샷과 대조. 기존 카드의 2영역 블록 모형은 아직 개발 중인 V2 구조를 확정된 현재 화면처럼 보이게 할 위험이 있어 교체.
  - 현재 앱처럼 **중앙 4방향 입력부**, 입력창, 하단 `En / Space / Enter`, 손가락 제스처 궤적 중심으로 재구성
  - 손가락은 CSS의 작은 애니메이션을 사용하며 `prefers-reduced-motion`에서는 정지
  - 입력 엔진의 자모 방향 Mapping을 임의로 확정해 표시하지 않음
  - 공식 앱 아이콘 `/assets/app-grigle-launcher.webp` 유지
- **MY LOCK**: 임의 CSS 도형 3개 제거. **Candy Soft R2 승인 원본**인 `/assets/mylock-candy-soft-trio.webp`를 그대로 사용. 작은 잠금 화면 목업에 9:41, 공식 앱 아이콘을 배치
- 두 카드 모두 **276×194px 고정**, DZlog 260×400px 및 12px 간격, 좌측 문구, 헤더, 하단 좌표는 변경 없음
- `scripts/check.mjs`: V4 카드 외곽 치수, 그리글 제스처, MY LOCK 승인 자산 사용, 하단 배치, PC/모바일 경계 등 회귀 정적 검사 추가
- `main`·운영 Cloudflare·Vercel 프리뷰 변경 없음
- **한계:** 반영은 소스 기준. 브라우저 실화면/전체 `npm run build`은 GitHub Actions runner가 시작되지 않아 아직 통과 확인 불가. 최종 디자인 승인과 구분
