# Stitch에 복사할 그리글 카드 디자인 프롬프트

프로젝트 이름: `DDZ-Grigle-Card-Pilot`
상태: **디자인 시안 대기 — 실제 코드 수정 금지**
이 문서는 Google Stitch 채팅에 복사하여 사용할 목적으로 작성했습니다.

## 첫 생성 — A안

두도지공방 홈페이지의 **기존 그리글 카드 한 장**만 고도화하는 디자인 시안을 생성해줘. 전체 웹사이트, 대시보드, 앱 화면을 새로 만들지 마.

**카드 외곽 규격:** 정확히 가로 276px × 세로 194px, 가로 카드 1개. 둥근 모서리와 밝은 세이지그린/아이보리/절제된 브라운 톤. 화면 비율을 276:194로 유지하고, 작은 크기로 축소해도 읽혀야 해.

**고정 콘텐츠:**
- 왼쪽 상단: 제공한 **그리글 공식 앱 아이콘** + 이름 "그리글"
- 왼쪽 텍스트(2줄): "방향으로 입력하는" / "새로운 한글 키보드"
- 오른쪽: 작고 심플한 **한글 방향 제스처 키보드 콘셉트**. 입력창, 중앙 상·하·좌·우 입력 방향 표시, 필요할 때만 En / Space / Enter를 넣어.
- 손가락 제스처는 손가락이 패널을 크게 가리지 않도록 절제된 한 개의 짧은 이동 궤적으로 표현.
- 실제 앱과 동일한 완성 화면이 아니라 기능을 이해시키는 시각적 예시야.

**중요 금지사항:** 그리글은 손글씨·그림·메모 앱이 아님. 임의 잎사귀·다른 로고로 공식 아이콘을 바꾸지 마. 아직 확정되지 않은 V2 자모별 제스처 매핑, 실제로 없는 기능·키 배열을 창작하지 마. 보라색 강조, 상태 배지, 마케팅 문구, 설정 화면, 상단 홈페이지 헤더·다른 앱 카드 추가 금지.

**A안 스타일:** 키보드 입력부가 가장 잘 읽히는 정돈된 프리미엄 미니멀 카드. 카드 외곽과 문구 위치는 기존 Hero v4의 배치를 존중해줘.

결과로 카드 **단독 이미지 1개(A안)**와 장점·한계 각 2개, 실제 웹 구현 시 바뀌는 내부 요소를 알려줘. 실제 CSS나 GitHub 파일은 수정하지 마.

## 두 번째 생성 — B안

앞서 만든 A안을 기준으로 외곽 크기 276×194px, 공식 아이콘, 한국어 문구, 베이지/세이지 톤을 **모두 그대로 유지**하고 카드 내부만 변형해줘.

이번 B안은 **손가락의 이동 방향을 직관적으로 느낄 수 있는 제스처 표현**을 조금 더 강조해줘. 과도한 화살표나 번쩍이는 이펙트는 피하고, 키보드와 텍스트 가독성은 A안과 동등하게 유지해.

다른 두 카드, 배경, 홈페이지 전체 구성을 포함하지 마. 결과로 **B안 단독 이미지 1개**와 A안과의 차이 3가지만 제시해줘. 실제 코드를 작성하거나 배포하지 마.

## Stitch에 함께 업로드할 자료

1. PC Hero v4의 **그리글 카드 영역만** 캡처한 이미지 (가능하면 배경 맥락이 보이는 전체 Hero 화면도 한 장).
2. 공식 아이콘: `public/assets/app-grigle-launcher.webp` (GitHub 작업 브랜치에 저장).
3. 사용자가 이전에 보여준 그리글 실제 키보드 캡처 (가능하다면).

참고 URL(자료 확인용): `https://github.com/Dudozi-workshop/dudozi-workshop-site/blob/feat/homepage-visual-r3-hifi/docs/GRIGLE_STITCH_PILOT.md`

Stitch가 URL을 읽지 못하면 이미지를 직접 첨부한다. 이 링크만으로 저장소를 읽거나 변경할 권한이 생기지 않는다.
