# 두도지공방 PC 홈 히어로 R4.5 · 사진·재질 중심 개선

* 작성일: 2026-10-14
* 작업 브랜치: `feat/homepage-visual-r3-hifi`
* 기준 방향: 기존 R4 / 대표 앱 중심 따뜻한 공방형 디자인
* 적용 범위: 홈페이지 첫 페이지 히어로(PC 1100/1280/1440px)만 우선 개선

## 디자인 원칙
- 좌측 메인 문구, 중앙 DZlog 스마트폰, 우측 3개 앱 포스터의 3축 구성 및 DDZ 로고 유지
- 브랜드 톤: 아이보리·베이지·세이지그린·브라운. 광원은 한 방향의 따뜻한 자연광
- 배경은 한 장의 고해상도 사진을 기본으로 하고 별도 저해상도 오려낸 소품은 더하지 않음
- 그림자는 실제 접지(물체가 바닥에 닿는 느낌)를 기준으로 절제. 임의 이미지에 마스킹+그림자를 중첩해 떠 보이게 만들지 않음
- DZlog는 기록 카메라. 그리글은 방향 제스처 키보드. MY LOCK은 취향형 잠금 화면
- 실제 앱 화면이 아닌 표현은 '구성 예시' 표시 유지

## 1차 구현 완료 항목 (R4.5)
1. 히어로 배경 외부 원본 사진 요청 품질을 `w=2560&q=88`로 상향; 읽기 영역은 단일 자연광 오버레이로 유지
2. 원본 해상도가 낮은 `desk-books.webp`(250x63)와 `leaf-edge.webp`(90x165)의 별도 배경 합성 비노출
3. `podium.webp`(340x85) 확대 이미지 대신 CSS 접지 그림자로 대체
4. 배경 이미지의 중복 선언을 R4 스타일시트 한 곳으로 정리하여 이후 변경 충돌 예방
5. 앱 카드 반투명 질감, 자연광 하이라이트, 그림자 강도를 같은 기준으로 맞춤
6. 회귀 검사에 저해상도 소품 재등장 방지 추가
