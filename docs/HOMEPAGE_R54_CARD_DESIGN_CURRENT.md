# 두도지공방 홈페이지 R5.4 — 카드 디자인 현재 기준 (2026-10-31)

> **단일 현재 기준 문서** · 상태: 디자인 시안 검토 중 / **이미지 최종 승인 전** / **미구현**.  
> 운영 `main` R5.3 및 배포 변경 금지. 이 문서는 `design/homepage-r54-card-study-20261026` 브랜치의 **디자인 기록**이며, 앱 화면 구현 사양/승인 완료 증빙이 아니다.

## 1. 유지할 결정

- **배치**: 왼쪽 DZlog 세로 카드 1장 + 오른쪽 위 그리글 가로 카드 1장 / 오른쪽 아래 MY LOCK 가로 카드 1장 (**1+2**). 세로 카드의 맨 위·아래와 우측 두 카드 묶음의 맨 위·아래 정렬.
- **분위기**: R5.3의 따뜻한 햇살·크림 벽·나무 책상 배경과 슬로건/CTA/하단 일체형 반투명 바 유지. 카드에는 아이보리/세이지/라벤더의 자연스러운 입체감과 적정 여백.
- **구현 방향(후속)**: 앱마다 **완성된 고화질 정적 카드 이미지 1장 + 카드 전체를 클릭할 수 있는 링크**. 스마트폰 내부 움직임, 카드 내부 분할 애니메이션, 개별 HTML 장식 오브젝트 **불필요**. 접근성 링크명 및 대체 텍스트는 적용.
- **공식 아이콘**: 이미지 생성 AI가 임의로 그린 유사 아이콘 사용 금지. 사이트 저장소 공식 원본을 최종 이미지에 *직접* 합성:
  - DZlog `public/assets/app-dzlog-launcher.webp`
  - 그리글 `public/assets/app-grigle-launcher.webp`
  - MY LOCK `public/assets/app-mylock-launcher.png`
- **시안 검토 중에는 코드 구현/병합/배포 금지**. 이미지 최종 승인 후 별도 브랜치와 프리뷰 QA로 진행.

## 3. 문구와 앱별 금지 사항

- DZlog 메인 **“사진과 기록을 한 번에”**, 보조 **“촬영과 동시에 자동 저장·분류”**. 사용자가 설정한 저장 규칙/경로/파일명에 따라 정리하는 앱이므로 **사진 콘텐츠 AI 인식 분류처럼 표현 금지**.
- 그리글 **“방향으로 입력하는 새로운 한글 키보드”**. 세로형 C안은 **키패드 입체감의 참고**이지 그대로 세로형을 홈페이지 카드에 적용하라는 의미가 아님. 실제 한글 IME와 다른 일반 자모 키 배열·손가락/손 그림·추가 인셋 카드 금지.
- MY LOCK의 독립 스타일을 유지하고 불필요한 디자인 변경 금지.
- 세 앱의 실제 기능과 무관한 가상 스크린샷을 **실제 앱 화면**이라고 소개하지 말 것.

## 5. 다음 검수 / 완료 조건

1. **공식 아이콘 원본 정밀 합성**: 실제 3종 아이콘을 픽셀/색/비율 왜곡 없이 넣고 생성형 유사 아이콘 잔여물 제거.
2. **그리글 키패드 화면 일체감 검수**: 둥근 사각 입력 패널이 폰에 붙은 별도 이미지처럼 보이지 않는지, 방향 네 개만 있는지, 한글 자모 키가 재등장하지 않는지 확인.
3. **비율 재확인**: 과거 논의 목표 **좌:우 약 43:57**과 현재 추출 이미지 폭 **710:839(약 46:54)**는 다름. 우측 카드 높이도 **464 / 390**으로 동일하지 않음. 좌·우 묶음 상하 끝선은 맞지만, 최종 그리드·상하 균등 분할 여부를 **이미지 시안에서 재검토**; 사용자 지시 없이 수치 확정/강제 변환 금지.
4. 한글 문구, 파일명·날짜 등의 오류와 기능 오인 요소, 스마트폰/폴더/기록물의 잘림, PC·모바일 크기에서 가독성 검수.
5. 사용자가 **카드 3종 최종 이미지 승인**한 이후 별도 구현 브랜치/PR 및 비운영 프리뷰 QA. 운영 R5.3 변경은 별도 승인 필요.
